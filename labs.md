## Scribbler

**Browser-native executable JavaScript notebooks**

Scribbler is an executable JavaScript notebook that runs entirely in the browser. It combines JavaScript, AI models, browser APIs, local files, data visualization, and interactive UI into a single shareable document with zero installation.

**Highlights**

- Browser-native execution
- AI integration
- Interactive visualizations
- Browser APIs
- Scientific computing
- Publish and share notebooks
- Intel AI PC / OpenVINO collaboration

**Status:** Available for strategic acquisition, licensing, or OEM partnership.

---

## LocalCode

**Private AI coding assistant for local models**

LocalCode is an AI coding environment that combines modern coding agents with local LLMs running through OpenVINO and native inference engines. It enables private, offline software development without relying on cloud-hosted models.

**Highlights**

- Local AI models
- OpenVINO acceleration
- Multi-platform support
- Integrated code agent
- Privacy-first architecture

**Status:** In development.

---

## EntropyFlow

**Machine learning inference framework**

EntropyFlow is an experimental framework for building efficient inference systems using ensemble machine learning techniques. It explores alternatives to transformer architectures for language modeling and prediction.

**Highlights**

- LightGBM ensembles
- Efficient inference
- Language modeling
- High-performance prediction
- Experimental AI research

**Status:** Enterprise licensing and research collaborations.
